
# Caja Concurrente en Java

## Descripción
Este proyecto simula las ventas de una tienda utilizando programación concurrente en Java 21.

Tres vendedores realizan 5 ventas de C$100 cada uno, utilizando `Thread` y `Runnable`.

Se utiliza `synchronized` para evitar race conditions y `join()` para esperar que todos los vendedores terminen sus ventas.

## Resultados
- **Cantidad de ventas:** 15
- **Total recaudado:** C$1,500
- **Lenguaje:** Java 21
